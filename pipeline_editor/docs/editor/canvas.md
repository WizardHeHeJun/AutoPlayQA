# 看懂画布

画布上的每一个视觉元素都对应任务 JSON 里的某个字段，这一页把它们逐一对上号。

**节点卡片**从上到下是：步号徽章 + 节点名（include 节点再加一个锁图标）→ 正文 → `next → …`
页脚（详情模式）→ 状态徽章。

详情模式下卡片按 识别（蓝）/ 动作（橙）/ 其他（灰）三组展开参数行，
页脚是 `next → …`，底部一行是状态徽章。

- **步号**由后端算：主干 `1,2,3…`（从 `entry` 沿 `next[0]` 走），分支 `2.1`；
  显示 `?` 表示没被编号（从 `entry` 沿 `next`/`on_timeout` 走不到它）。
- **正文**受工具条「详情」开关控制：
  - 开（默认开）：按 `识别 · <type>`（蓝）/ `动作 · <type>`（橙）/ `其他`（灰）
    三组列出该节点**自己写了的**参数行（`roi` / `template` / `target` / 时序等），
    常用字段的中文说明挂在 label 的 tooltip 上，值太长悬停看全文。
    注意这里**只显示节点自身字段**，任务级 `defaults` 不会渗进来——避免误以为
    defaults 已经固化到节点上。
  - 关：回到两行摘要 `👁 识别摘要` / `⚡ 动作摘要`。
- **状态徽章**：`入口`、`终点 ✓`（`next` 为空）、`⏱ 超时兜底`、`🚩 finding`、
  `⚠ n`（本地 lint 警告数，悬停看内容）、`✗ 校验错误`。
- **边**三类：`next` 实线（同一个源有多条时，边中点显示 1/2/3… 即识别优先级顺序）；
  `on_timeout` 橙色虚线；`on_finding` / watchdog `skip_to` 的紫色点划线**默认隐藏**，
  打开工具条「跳转层」开关才画出来，它们从一个名为「任务级」的虚拟节点发出
  （这个节点不属于任务 JSON，只是视图）。
- **连接点**（悬停节点时出现的小圆点）：底部蓝色 = `next` 源，右侧橙色 = `on_timeout` 源，
  顶部灰色 = 目标。
- **include 节点**：灰底虚线框 + 锁图标，来自 `includes` 引进的共享片段
  （悬停锁看来源文件）。它们只读、保存时自动剔除，绝不会被固化进主文件。

> [!WARNING]
> 已知缺口：从 include 节点**拖出**连线在界面上不会被拦，但保存时整个节点会被剔除，
> 这条改动会静默丢失——要改片段请去片段文件里改。
