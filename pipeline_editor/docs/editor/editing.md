# 编排：连线、删边、增删节点

改图的所有入口都在这一页：哪些操作在画布上做，哪些必须去属性面板。

想做什么 → 去哪里做：加一条流程分支 → 在画布上从源节点底部蓝点拖线到目标；
调识别优先级 → 属性面板「节点」Tab 的 next 列表拖手柄排序；
删一个节点 → 属性面板「节点」Tab 右上角的红色垃圾桶（画布上的 `Delete` 只删边）。

- **选中**：单击节点 → 右侧自动切到「节点」Tab（运行中且你正停在「运行」Tab 时不抢焦点）；
  双击 = 强意图，任何时候都切过去。点画布空白 = 取消选中。左侧大纲、问题面板、
  运行事件流里的节点名同样可点，都会定位到该节点。
- **连线（加 next）**：从源节点**底部蓝点**按住拖到目标节点上松手 → 目标被追加到源节点的
  `next` 数组末尾（已存在则不重复加）。顺序就是识别优先级，想调顺序去属性面板的
  next 列表拖。
- **连超时兜底**：从源节点**右侧橙点**拖到目标 → 设置该节点的 `on_timeout`（单值，会覆盖）。
- **删边**：点一下边（选中后变蓝）→ 按 `Delete` 或 `Backspace`。删 `next` 边只从数组里
  移掉这一条（同一目标出现多次也能删对那条）；删橙色边 = 清空 `on_timeout`。
- **新建节点**：工具条「新建节点」→ 输入节点名 → 生成默认节点
  （`recognition: ocr`（expected 空）+ `action: click / target: recognized` + `next: []`），
  放在画布左上并自动选中，接着在右侧填参数、拖线接进流程。
- **删节点**：画布上的 `Delete` **只删边**（防误删）。删节点要在右侧「节点」Tab 右上角的
  红色垃圾桶按钮，确认后会一并清理所有指向它的 `next` / `on_timeout` /
  `watchdogs[].skip_to` / `on_finding`。
- **改名**：同一处的铅笔按钮。改名是级联的——`entry`、所有 `next`、`on_timeout`、
  `on_finding`、`skip_to` 一起改，成功后提示更新了多少处引用。
- **撤销 / 重做**：`Ctrl+Z` / `Ctrl+Shift+Z`（或工具条按钮），历史上限 100 步，
  切换任务时清空。历史里同时包含节点坐标，所以**一次拖动会压进多帧**，
  撤销时坐标是逐帧往回退的。
- **运行中**：工具条会显示「运行中（画布只读）」，连线与删边被禁用（保存/撤销/新建节点
  同样禁用），但节点仍可拖动调整布局。

## 布局、步号与视图开关

- **节点坐标**存 sidecar：`task/task_definitions/.layout/<任务名>.json`，
  停止拖动 1.5 秒后自动写盘，**不进任务 JSON**、不产生「未保存」标记、不污染 git diff。
- **自动布局**：工具条按钮，dagre 分层排版，按每张卡片的**实际渲染高度**算间距
  （详情模式下卡片更高也不会重叠），排完自动 fitView。
- **重排步号**：按当前图形重算步号并**整文件重写**回磁盘（主干 `1,2,3…`，分支 `2.1`）。
  因为是后端直接改文件，所以有未保存修改或正在运行时按钮禁用；成功后画布自动重载。
- **跳转层 / 详情**两个开关只影响画布展示，不改任务 JSON、不进撤销历史。
